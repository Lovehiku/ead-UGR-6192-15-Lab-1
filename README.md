Description

This C# project is a simple TodoItems API built with .NET. It demonstrates how to create RESTful APIs using MapGroup and endpoint routing. The API allows you to create, read, update, and delete (CRUD) todo items.

Features

✅ List all todo items (GET /todoitems)

✅ Get a single todo item by ID (GET /todoitems/{id})

✅ Create a new todo item (POST /todoitems)

✅ Update an existing todo item (PUT /todoitems/{id})

✅ Delete a todo item (DELETE /todoitems/{id})
